# 日本の「3兆円AI投資」が、B2Bデータ市場を変える——プロダクトを作る側から見えていること

日本の AI 投資額が3兆円規模に達しました。ソフトバンクが三大メガバンクと合弁会社を設立し、1兆パラメータの AI モデル開発に乗り出すというニュースは、単なる大企業の動きではありません。米国・中国に次ぐ世界第三位の投資規模です。

私はプロダクトデザイナーとして、日本の B2B 市場向けに500万社の企業データベース「GBaseGTM」を開発しています。エンジニアではなく、コードも書きません。AI ツールを使ってプロダクトを設計し、毎週何かしら shipping しています。そんな立場から、この3兆円という数字が何を意味するのか、考えてみたいと思います。

## 「予算がつく時代」がようやく来た

日本企業の IT 投資は、長年にわたって先進国の中でも低水準にとどまってきました。この数年でようやく変化の兆しが見え始め、AI に対しても本格的に予算を割く企業が増えてきています。

3兆円という金額は、その流れが一気に加速したことの証です。しかも今回の投資は、単に海外の AI サービスを導入するという話ではありません。ソフトバンクとメガバンクの合弁という形が示しているのは、日本独自の AI 基盤を自前で構築するという強い意志です。

この背景にあるのは、データ主権に対する日本企業の感度の高さだと感じています。法人番号体系や個人情報保護法の厳格さを考えると、企業データを海外に出すことへの抵抗は根強いものがあります。特に金融機関が主導している点は象徴的です。もっとも機密性の高いデータを扱う業界が、AI の自主化に本気で動いているわけです。

## Agent の時代に「何をやらせるか」が問われている

もうひとつ、今週印象的だったのは GitHub の動きです。2月17日、GitHub が Claude Code、Copilot、OpenAI Codex の三つの AI Agent を GitHub Actions に統合する技術プレビューを発表しました。

日経も2026年を Agent が企業利益に貢献する元年と報じています。米国では McKinsey が Agent 経済の規模を2.9兆ドルと試算し、中国でも清華大学の AGI-Next サミットで「チャット型 AI の時代は終わった」という共通認識が示されました。米中日が同時に同じ方向を向いているのは、一過性のブームとは明らかに異なります。

ここで重要なのは、Agent の技術そのものはすでにコモディティ化が進んでいるという点です。GitHub が三社の Agent を並列で扱っていること自体が、その証拠とも言えます。Agent の「信頼性インフラ」を手がける Temporal は50億ドルの評価額で3億ドルを調達しましたが、収益が前年比380%で伸びているということは、それだけ Agent がまだ不安定で、信頼性に対するニーズが大きいということでもあります。

では、差別化はどこで生まれるのか。私は「Agent に何をやらせるか」を定義する層だと考えています。エンジンの性能ではなく、タスクの設計です。先週リリースした PM-Quill は、まさにそこを狙ったプロダクトです。Agent に対して /spec、/feasibility、/plan、/review という4つのステップで構造化されたタスクを定義し、プロダクトの意思決定を支援します。

## 日本の B2B データ市場に開いた窓

話を日本市場に戻します。

3兆円の AI 投資が意味するのは、日本企業が AI に「本気で予算をつけ始めた」ということです。予算がつくということは、ツールやデータへの需要が具体的に生まれるということです。

GBaseGTM で500万社の日本企業データベースを構築しているのは、この流れを見据えてのことです。法人番号をベースにした構造化データは、AI Agent が企業分析や営業支援のタスクを実行する際の基盤になります。データが海外に出せないのであれば、国内にあるデータの価値は相対的に高まります。

ただし、この窓がいつまでも開いているとは考えていません。大企業が自前の AI 基盤を構築するには、日本企業の意思決定サイクルを考えると18ヶ月から24ヶ月はかかるでしょう。その間に、スタートアップや小規模チームが先行してプロダクトを届けられるかどうかが勝負です。

## 非エンジニアでも AI プロダクトは作れる

最後にひとつ、伝えたいことがあります。

私はコードを書きません。Claude Code や Cursor といった AI ツールを使って、プロダクトの設計と開発を進めています。それでも毎週何かしらの機能をリリースし、ユーザーに届けることができています。

**Agent の時代に求められるのは、エンジンを作る力ではなく、Agent に「何をやらせるか」を定義する力です。** それはプロダクトマネージャーやデザイナーがずっと磨いてきたスキルそのものだと思っています。

日本の3兆円 AI 投資は、技術者だけでなく、プロダクトを考える人にとっても大きなチャンスの始まりです。自分自身、GBaseGTM と PM-Quill を通じて、この波に乗っていくつもりです。

同じように AI プロダクトに取り組んでいる方がいれば、ぜひ note のコメントで教えてください。

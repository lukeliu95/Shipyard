# 「AI二極化元年」に思うこと——使い方を設計できる人が勝つ時代

今週、JBpress の記事に目が止まりました。2026年を「AI二極化元年」と断言する内容です。AIが効くか効かないかではなく、**使い方を設計できた企業だけが勝つ**という主張でした。

プロダクトデザイナーとして毎週 AI プロダクトを出荷している自分にとって、この言葉は今週読んだどのニュースよりも刺さりました。

## 56%がゼロリターンという現実

アメリカでは今週、AI に関する厳しい調査結果が相次ぎました。PwC の調査によれば、AI に投資した企業の56%がリターンゼロだったといいます。Fortune と NBER が6000人の CEO・CFO を対象に行った調査では、AI が生産性に「ほぼ影響を与えていない」という結果が出ています。さらに、ハーバード・ビジネス・レビューと UC Berkeley の研究では、AI が業務負荷をむしろ増やしており、若手社員の62%が燃え尽き症候群を感じているとのことです。

これだけ見ると「AI は期待はずれだった」という結論になりそうです。しかし同時に、まったく逆のデータも出ています。Gartner によれば、企業アプリケーションにおける Agent の組み込み率は前年比800%で成長し、5%未満から約40%に跳ね上がりました。

導入は爆発的に進んでいるのに、効果はゼロ。この矛盾をどう説明すればいいのでしょうか。

## ソフトバンク250万Agentが教えてくれること

この矛盾を考えるうえで、ソフトバンクの事例は示唆に富んでいます。わずか2.5ヶ月で全社に250万の Agent を導入し、社員一人あたり100個の Agent が稼働しているといいます。

この実行力は日本企業として見事です。ただ、ここで立ち止まって考えたいことがあります。250万という数字は「導入量」であって、「効果」ではありません。導入した Agent がどんな業務フローの中で、どんな役割を果たしているのか。そこが見えないかぎり、数字だけでは判断できないのです。

アメリカの56%ゼロリターンの企業がやっていたことは、既存の SaaS ツールに「AI ボタン」を追加しただけだったと言われています。メールに Copilot を入れる、カスタマーサポートにチャットボットを置く、ドキュメントツールに要約機能をつける。業務の流れ自体は変えず、上からAIをかぶせただけです。

JBpress が指摘した「二極化」の本質はここにあります。効果が出ているのは、既存のやり方に AI を足した企業ではなく、AI を前提にワークフローそのものを設計し直した企業だけだということです。

## 「実装」の四つの証拠

日本では今週、AI の「実装」が複数の方向から同時に裏付けられました。学術界では SBbit が算力の制約と向き合う議論を展開し、商業界では JBpress が二極化を宣言しました。産業界では東洋経済が国策としての AI 推進を報じ、執行の現場ではソフトバンクが250万 Agent の実績を示しています。

学術・商業・産業・執行という四つのレイヤーが同時に動いているのは、AI が「話題」から「実装」のフェーズに移ったことを意味しています。議論の段階は終わり、実際に使いこなせるかどうかの勝負が始まっています。

## ワークフロー設計という仕事

私はエンジニアではありません。コードは書きませんが、Claude Code や Cursor といった AI ツールを使って、毎週プロダクトを出荷しています。

先週リリースした PM-Quill は、プロダクトの意思決定を支援するツールです。/spec → /feasibility → /plan → /review という4つのステップで、Agent に構造化されたタスクを定義します。これは既存のプロセスに AI を追加したものではなく、AI が参加することを前提に一から設計した新しいワークフローです。

GBaseGTM も同じ考え方で作っています。500万社の日本企業データを AI Agent が活用できる形に構造化し、営業チームの調査プロセスそのものを再設計しています。

こうした経験を通じて感じるのは、**AI の効果を左右するのは技術力ではなく、ワークフローの設計力だ**ということです。Agent のエンジンがどれだけ優秀でも、「何を、どの順番で、どこまで任せるか」を設計しなければ、効果は出ません。

そしてこの設計力は、エンジニアだけのものではありません。ユーザーの課題を理解し、業務の流れを整理し、人と AI の役割分担を決める。これはプロダクトマネージャーやデザイナーがずっと磨いてきたスキルそのものです。

## 二極化時代のチャンス

56%のゼロリターンは、AI にとっての悪いニュースではないと思っています。むしろ、ワークフローを設計できる人にとっての追い風です。ほとんどの企業が AI の使い方を見つけられていないということは、そこに大きな需要があるということです。

二極化の時代に求められるのは、より高性能な AI モデルではなく、AI を活かすワークフローを設計できる人です。エンジニアでなくても、そこに貢献できる。自分自身の経験が、その一つの証明になればと思っています。

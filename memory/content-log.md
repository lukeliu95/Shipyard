# Content Log — 内容生产记录

> 每次生成内容后自动追加一条记录。这是 Shipyard 的核心记忆。

## 格式说明

每条记录包含：
- **日期** — 生成日期
- **平台** — twitter / wechat / note
- **内容线** — signal / build_log / methodology
- **标题/slug** — 内容标识
- **输入素材** — 来源简述
- **状态** — draft → reviewed → published
- **输出文件** — 文件路径

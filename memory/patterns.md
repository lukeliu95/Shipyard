# Patterns — 内容模式积累

> 从多次内容生产中提炼出的可复用模式。
> 什么类型的素材适合什么平台、什么角度效果好、什么写法要避免。

## 素材 → 平台匹配模式

### P001: mckinsey-analyst 前置分析显著提升内容质量
- **发现日期：** 2026-02-18
- **模式：** 在调用 cn-to-substack-essay / cn-to-jp-note-writer 之前，先用 mckinsey-analyst 对素材做三层金字塔分析（表面数据 → 深层驱动 → 战略启示），产出的因果链和二阶效应可以直接作为内容角度的选择依据
- **效果：** #007 #008 的洞察深度明显高于 #001-#006（后者是直接从素材生成）
- **建议：** 素材信号密度高时（>3 条强信号），优先调用 mckinsey-analyst 前置分析

### P002: 日本市场内容必须有本土数据锚点
- **发现日期：** 2026-02-18（从 #003 #006 #008 三篇 note 积累）
- **模式：** note 读者对全球性趋势的关注度远低于"这件事对日本意味着什么"。每篇 note 必须有一个日本本土数据锚点（法人番号、日经报道、日本企业投资数据等）
- **效果：** #008 以 3 兆円投资为锚比 #003 以恐慌为切入更贴合 note 读者

## 高效写法模式

### P003: Signal Report 的去重策略
- **发现日期：** 2026-02-18
- **模式：** 同一大主题（如 SaaSpocalypse）可在 7 天内出现在多篇内容中，但必须换角度。#001 从定价权角度切，#007 从任务定义层角度切，避免了去重冲突
- **规则：** 去重检查的对象是"角度"而非"信号源"。同一信号源换角度后可复用

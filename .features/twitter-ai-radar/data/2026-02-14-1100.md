## 美国

### Anthropic — Claude 4 系列发布 + $300 亿融资
- **内容**: Anthropic 发布 Claude Opus 4 和 Claude Sonnet 4。Opus 4 在 SWE-bench 达 72.5%，Terminal-bench 43.2%，可连续工作数小时。Claude Code 正式 GA，支持 GitHub Actions 后台任务。新增 4 个 API 能力：代码执行工具、MCP 连接器、Files API、1 小时 prompt 缓存。此外，$300 亿 Series G 融资（估值 $3800 亿）由 The Register 报道。
- **为什么重要**: Claude 5 推理成本预计大幅下降，Anthropic 正在从"最好的模型"向"最好的平台"转型。MCP 连接器 + Files API 意味着 Agent 工具链的标准化加速。

- **为什么重要**: microGPT 是极好的教育资源。"slopacolypse"概念如果被广泛接受，将催生内容质量过滤/鉴别工具的新需求——这是创业方向。

### Coinbase — Agentic Wallets + x402 协议
- **内容**: Coinbase 正式上线 Agentic Wallets，允许 AI Agent 独立持有和发送加密货币。x402 协议已处理超 5000 万笔交易，支持 machine-to-machine 支付。Base 链上 Agent 交易免 gas 费。Google AP2 协议联合 Coinbase、PayPal、Mastercard 等 16 家建立 Agent 支付标准。
- **为什么重要**: Agent 经济的基础设施正在快速成型。x402（HTTP 402 复活）+ AP2 双协议竞争，意味着"Agent 如何付钱"这个问题正在被认真解决。这是 Web3 最有实际价值的 AI 应用场景。

### Claude 5 动态

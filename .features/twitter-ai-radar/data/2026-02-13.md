### 1. Claude Cowork 引发「SaaS 末日」— $2850 亿蒸发
- 来源：Fortune、VentureBeat、多家财经媒体
- Anthropic 的 Claude Cowork（桌面自主 agent）1月13日发布 macOS 版，2月10日登陆 Windows

### 2. Claude Opus 4.6 发布 — 2月5日
- 来源：Anthropic 官方、Bloomberg、Fortune

- Claude Code 也同步更新
- **为什么重要**：这是 Alan 的「底层引擎」升级。更强的推理 = 更好的信号分析

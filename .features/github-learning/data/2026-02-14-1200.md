## 关键趋势总结

### 1. Spec-Driven Development 崛起
GitHub 官方 spec-kit 69K 星 = vibe coding 的下一阶段。从"让 AI 随意写"进化到"先定义 spec 再让 AI 实现"。这是从混乱走向工程化的必然路径。

### 2. OpenClaw 生态大分化
- 官方 OpenClaw: 190K 星（巨无霸）
- NanoClaw: 7.8K（安全优先，容器隔离）
- MimiClaw: 1.3K（$5 芯片，极致便宜）
- PicoClaw: 6K（$10 RISC-V，边缘 AI）
- **信号**: 个人 AI 助手正在形成「云端 → 桌面 → 芯片」的完整光谱

### 3. MCP 生态继续扩张
Chrome DevTools MCP + Excalidraw MCP = 更多大项目官方入场。Agent 的工具箱从「读写代码」扩展到「浏览器调试 + 画图」。

### 4. 知识图谱型记忆兴起
Rowboat（知识图谱）+ Beads（依赖图 + 语义压缩）= AI 记忆从简单存取进化到结构化积累。"记忆是积累，不是检索"的理念正在成为共识。

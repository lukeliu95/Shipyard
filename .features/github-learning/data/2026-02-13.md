## 趋势观察

### Generative UI 正在爆发
今天最明显的趋势是 **Generative UI**：AI 不再只生成代码或文本，而是直接在运行时生成/选择/控制 UI 组件。这是从「AI 写代码给人看」到「AI 直接造界面给人用」的跃迁。

关键项目：Tambo（React SDK）、Thesys/Crayon（API 返回 UI）、CopilotKit（开源示例）、A2UI（Google 的跨平台方案）

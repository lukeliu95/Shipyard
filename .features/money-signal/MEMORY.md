# Money Signal

> 从 GitHub 趋势和 Twitter 动态中提炼最有可能赚钱的机会，通知 Luke
> 更新：2026-02-12

## 当前状态
初始化阶段。依赖 github-learning 和 twitter-ai-radar 两个上游 feature 的数据。

## 目标
- 从 GitHub 高星项目中识别商业化机会（能做成产品的、能提供服务的）
- 从 Twitter 讨论中发现未被满足的需求（人们在抱怨什么、在找什么工具）
- 综合判断后给 Luke 发通知：「这个东西可能能赚钱，原因是...」

## 判断标准（待迭代）
- 需求真实性：是不是真有人要？
- 竞争格局：现在谁在做？做得好不好？
- Luke 能力匹配：以 vibe coding + AI 辅助，Luke 能不能做出来？
- 变现路径：怎么赚钱？订阅？一次性？广告？

## Gotchas
- 赚钱信号有时效性，发现了要快速通知
- 避免噪音：不是每个热门项目都是机会，要过滤
- Luke 的优势是产品设计 + AI 辅助编码，不是硬核技术，机会要匹配这个能力圈

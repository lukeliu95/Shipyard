# 赚钱信号分析 — 2026-02-12

## 信号 1: AI 记忆/上下文管理工具

**信号强度：强**
**来源：** claude-mem（3天涨 5K stars）+ 我们自己在做的 .features/ 记忆系统

**是什么：** AI 编码助手的"记忆"问题是公认痛点。每次新会话，AI 忘了之前做过什么。claude-mem 用自动记录+压缩+注入的方式解决，市场反应爆炸。

**为什么能赚钱：**
- 需求真实：每个用 AI 编码的人都遇到过这个问题
- claude-mem 只支持 Claude Code，Cursor/Windsurf/Copilot 用户怎么办？
- 记忆管理可以做成跨工具的通用层

**竞争情况：** claude-mem 是先行者但只做 Claude Code 插件。跨编辑器、跨 AI 工具的记忆层还没人做好。

**Luke 能做吗：** 能。产品设计是核心差异化，技术上可以基于 claude-mem 的思路做。MVP 预估 2-3 周。

**建议动作：** 深入研究 claude-mem 的实现，思考一个跨工具的 AI 记忆产品的产品形态。

## 信号 2: 个人 AI 助手（非 ChatGPT 的替代品）

**信号强度：强**
**来源：** openclaw（145K stars）+ Personal_AI_Infrastructure + 跨国共振

**是什么：** 用户不满足于 ChatGPT 这样的通用 AI，想要一个真正"自己的"AI 助手 — 了解自己、持续学习、本地运行、数据自控。

**为什么能赚钱：**
- 需求确认：openclaw 5 天 66K stars，这不是噪音
- 痛点明确：通用 AI 不了解你、记不住你、数据在别人手里
- 市场空白：开源方案门槛太高，普通人用不了

**竞争情况：** openclaw 是开源，技术型用户自己部署。但"让普通人也能拥有个人 AI"这个市场没人做好。

**Luke 能做吗：** 有挑战但值得尝试。核心是产品设计 — 如何让"配置个人 AI"变得像设置手机一样简单。技术层可以站在 openclaw 等开源项目的肩膀上。

**建议动作：** 先体验 openclaw，找到普通用户用不了的痛点，设计一个"10 分钟拥有你的 AI"的产品方案。

## 信号 3: AI agent 替代 SaaS 的工具层

**信号强度：中**
**来源：** Claude Cowork 冲击 SaaS + 美日跨国共振

**是什么：** AI agent 正在替代传统 SaaS。以前你需要买一个项目管理工具、一个 CRM、一个客服系统，现在一个 AI agent 可能全做了。但中间需要"连接层"和"定制层"。

**为什么能赚钱：**
- SaaS 市场巨大，被颠覆的过程中有巨大机会
- 企业不会一夜切换，需要过渡工具
- "AI agent 定制工坊"可能成为新品类

**竞争情况：** 赛道刚起来，Emergent（$300M 估值）是标杆但面向开发者。面向非技术用户的"AI 替代你的 SaaS"还没有好产品。

**Luke 能做吗：** 方向对但太大。建议先切一个垂直场景（比如 AI 替代某个具体的 SaaS）做 MVP。

**建议动作：** 观察，不急着做。先看哪些 SaaS 最先被 AI agent 替代，找到具体切入点再动手。

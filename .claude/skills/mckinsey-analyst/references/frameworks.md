# McKinsey 战略分析框架库

## 核心分析框架

### 1. 三层分析框架 (核心方法论)

**应用场景：** 所有报告分析

**三层结构：**
```
L3: 战略启示 (Strategic Implication)
   ↑ 
   ├─ 赛道/行业评分
   ├─ 投资优先级
   ├─ 风险-机遇矩阵
   └─ 5年行动路线图

L2: 深层驱动 (Root Cause & Mechanism)
   ↑
   ├─ 因果链路分析
   ├─ 系统性问题诊断
   ├─ 周期性 vs 结构性判断
   └─ 政策/技术/市场的真实影响

L1: 表面数据 (Surface Facts)
   ↓
   ├─ 关键数据点提取
   ├─ 趋势识别
   └─ 现象描述
```

**诊断流程：**
1. 提取数据 (10%)
2. 识别趋势 (15%)
3. 追问为什么 (40%)
4. 整合洞察 (20%)
5. 形成建议 (15%)

---

### 2. PEST分析 + 地缘政治维度

**标准PEST：**
- Political (政治)
- Economic (经济)
- Social (社会)
- Technological (技术)

**扩展维度 - 必须加：**
- Geopolitical Risk (地缘政治风险)
- Supply Chain Resilience (供应链韧性)
- Policy Continuity (政策延续性风险)

**诊断问题：**
- 短期冲击 vs 长期结构性变化？
- 企业主动适应 vs 被动应对？
- 政府政策与企业需求是否匹配？

---

### 3. 行业五力模型 + 中国威胁维度

**传统五力：**
1. Threat of new entrants (新进入者威胁)
2. Bargaining power of suppliers (供应商议价能力)
3. Bargaining power of buyers (买方议价能力)
4. Threat of substitutes (替代品威胁)
5. Rivalry among competitors (竞争对手竞争)

**关键扩展：**
- **中国威胁评估** (China Threat Assessment)
  - 中国企业是否在进入这个市场？
  - 中国的成本+规模是否威胁日本的品质溢价？
  - 日本的护城河是否在蚀化？

- **地缘政治维度**
  - 供应链集中度是否存在地缘政治风险？
  - 关键零部件/原料是否被纳入战略物资？
  - 贸易政策是否可能反转？

**诊断问题：**
- 谁在上升/下降？
- 为什么日本企业的地位在变化？
- 是否是结构性的（会长期持续）？

---

### 4. 价值链分析 + 位阶重排

**基础概念：**
产业从"原材料→制造→销售"分成多个环节，不同环节的价值（利润率）不同。

**位阶重排分析：**
```
过去：日本垄断某个环节（如精密零部件）→ 获得高利润
现在：中国进入这个环节 → 价格竞争 → 日本利润下降
未来：日本必须向更高价值的环节移动（如设计、品牌、战略物资）

诊断：日本从"零件供应商"→"战略物资提供者"的地位提升
```

**关键问题：**
- 我的产品在价值链中的位置是否在上升？
- 中国是否在打破我的价值链地位？
- 我是否有能力向更高价值的位置转移？

---

### 5. 四象限矩阵分析

**通用模板：**
```
        Y轴
        ↑
        │
   Ⅱ  │  Ⅰ
        │
────────┼──────→ X轴
        │
   Ⅲ  │  Ⅳ
        │
```

**常见应用：**
- X轴=市场吸引力，Y轴=竞争地位 → 投资优先级
- X轴=政策支持，Y轴=市场增长 → 赛道评分
- X轴=成本压力，Y轴=价格竞争力 → 企业困境
- X轴=供给约束程度，Y轴=利润潜力 → 机遇-威胁

**诊断流程：**
1. 确定两个最关键维度
2. 评估每个行业/企业在矩阵中的位置
3. 从位置推导战略含义
4. 识别位置的移动方向与速度

### 6. 因果链路推理

**从相关性到因果性：**

```
现象：A上升，B也上升
问法：这是因果关系吗？

实际情况示例：
现象：wage上升，物价上升
假设1：wage上升→企业成本增加→提价→物价上升（有因果）
假设2：外部通胀→企业提价，也给员工涨wage（共同原因）
诊断：需要看时间序列和逻辑链条

关键：找到"中间机制"而非仅看结果
```

**三层推理：**
1. **直接因果** (A→B)
   - 时间序列：A先发生，B后发生
   - 逻辑机制清晰
   - 例：关税↑→出口↓

2. **间接因果** (A→中间变量→B)
   - 需要找到中间环节
   - 例：关税↑→供应链调整→成本↑→利润↓

3. **共同原因** (X→A，X→B)
   - A和B都由外部X驱动
   - 例：经济衰退→需求↓，wage↓（不是wage导致需求下降）

### 7. 周期性 vs 结构性判断

**周期性变化：**
- 定义：会回到原点，或在区间内波动
- 特征：短期波动，趋势可逆转
- 企业应对：等待或微调
- 例：景气周期，库存周期

**结构性变化：**
- 定义：不会回到原点，趋势基本不可逆转
- 特征：长期单向移动，产业链条改变
- 企业应对：战略转向，激进改革
- 例：数字化替代纸张，中国威胁日本品质溢价

**诊断方法：**

问题1：最近10年的趋势是什么？
- 上升/下降/波动

问题2：这个趋势是否与经济周期相关？
- 经济好时趋势加强，经济差时趋势减弱 = 周期性
- 与经济周期无关 = 结构性

问题3：是否有政策/技术变化推动这个趋势？
- 有 = 可能结构性
- 没有 = 可能周期性

问题4：企业曾经逆转过这个趋势吗？
- 能逆转 = 周期性
- 无法逆转 = 结构性

### 8. 政策-企业错配诊断

**诊断框架：**

```
政策期望 vs 企业现实

政策关心：
- 战略产业的全球竞争力
- 5-10年的产业位阶
- 国家安全与供应链

企业关心：
- 今年能赚多少钱？
- 短期的成本压力
- 现金流与利润
```

**识别错配：**

症状1：政府补贴很多，企业投资却不多
→ 说明政策与企业关心的问题不匹配

症状2：企业最关注的问题（如物价、wage），政府政策不足
→ 说明政府偏离了企业痛点

症状3：企业在等待政策明确，市场却在加速变化
→ 说明企业被动，决策延迟

**后续风险：**
- 补贴效率低下（边际效应递减）
- 政策可能反转（财政压力）
- 企业缺乏内生动力

### 9. 赛道评分矩阵

**四维评估体系：**

维度1：**政策支持力度**
- 是否被列为重点产业？
- 补贴/税制优惠是否充足？
- 体制改革是否支持？

维度2：**市场增长动力**
- 需求增长是否确定？
- 周期位置是否对应？
- 国际市场是否扩大？

维度3：**竞争格局友好度**
- 日本是否保有防守能力？
- 中国威胁程度如何？
- 技术壁垒是否足够高？

维度4：**收益确定性**
- 投资周期长短
- 技术风险大小
- 市场反转风险

**评分标准：**
```
🟢🟢🟢 High Priority (三维都强)
  政策支持 ⭐⭐⭐⭐⭐
  市场增长 ⭐⭐⭐⭐⭐  
  竞争格局 ⭐⭐⭐⭐
  → 重点投资对象

🟡 Medium Hold (混合)
  某些维度强，某些维度一般
  → 选择性参与

🔴 Exit/Transform (防守弱)
  结构衰退已确定，或竞争对手领先
  → 战略收缩或转型
```

### 10. 企业决策框架

**三个关键问题：**

Q1：我在全球价值链中的位置是上升还是下降？
- 检查清单：产品成熟度 / 中国竞争 / 附加值率 / 客户质量

Q2：供给约束/地缘政治是我的机遇还是威胁？
- 机遇：高端制造、专业化、品质敏感
- 威胁：劳动密集、低差异化、成本竞争

Q3：我的产品在新地缘政治中属于哪一类？
- 战略物资 → 溢价机会
- 通用物资 → 竞争加剧
- 敏感物资 → 需求下降

## 常见错误与纠正

### 错误1：仅总结数据，不分析原因
❌ "2025年wage上升5.4%"
✓ "wage上升5.4%反映供给约束，这是结构性转变，意味着..."

### 错误2：将相关性当因果性
❌ "A增加，B也增加，所以A导致B"
✓ "A和B都可能由C驱动，需要检查时间序列"

### 错误3：混淆短期波动和长期趋势
❌ "纸张需求下降，等待反弹"
✓ "这是数字化替代，是结构性衰退，不会反弹"

### 错误4：忽视政策风险
❌ "政府补贴保证投资回报"
✓ "补贴可能在财政压力下反转，需要建立独立竞争力"

### 错误5：给所有企业同一个建议
❌ "所有企业都应该提价"
✓ "高端企业应该提价，劳动密集型应该自动化"

## 数据验证清单

分析任何报告前，检查：

- [ ] 数据来源是否权威？(官方统计 vs 问卷调查 vs 估计)
- [ ] 样本量是否足够？(439家 vs 44家企业的意义不同)
- [ ] 时间序列是否完整？(单点数据 vs 多年数据可信度不同)
- [ ] 是否存在幸存者偏差？(只统计了活着的企业)
- [ ] 定义是否一致？(去年的"wage上升"和今年的定义是否相同)

## 输出质量检查清单

完成分析后确认：

✓ 每个结论都有数据支撑或明确的逻辑推导过程
✓ 对关键数据的"为什么"追问了至少3层
✓ 区分了结构性变化 vs 周期性波动
✓ 识别了数据间的隐含因果关系
✓ 指出了报告缺失的关键问题
✓ 给出了可操作的优先级排序建议
✓ 从企业视角而非仅从数据角度分析
✓ 识别了后续需要深化的研究方向

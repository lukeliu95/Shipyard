## 五步分析流程卡片

### Step 1: 快速扫描 (2-3分钟)

**问题：**
```
□ 报告主题/行业/地域覆盖？
□ 时间跨度？(单年 vs 多年趋势)
□ 数据来源可信度？(官方统计 vs 问卷 vs 估计)
□ 核心是定量还是定性数据？
```

**输出：**
一句话总结 + 报告结构梗概

---

### Step 2: 数据提炼 (5-10分钟)

**关键数据表格模板：**

| 指标 | 数值 | 同期对比 | 历史高位 | 性质 |
|------|------|--------|--------|------|
| wage增长 | 5.4% | +3pp | 33年高位 | 结构性↑ |
| 利润率 | ? | ? | ? | 趋势? |
| 市场需求 | ? | ? | ? | 增/减? |

---

### Step 3: 原因分析 (10-15分钟) ⭐ 关键

**三层为什么模板：**

```
现象：[数据]

为什么1：企业/政策/市场的直接反应是什么？
答：

为什么2：这背后的系统性驱动是什么？
答：

为什么3：这反映的深层变化是什么？
答：

结论：这是周期性还是结构性？
```

---

### Step 4: 战略洞察 (10分钟)

**三个关键问题：**

```
Q1: 这个趋势对我的行业/企业意味着什么？
    机遇？威胁？两者都有？

Q2: 哪些企业会赢？哪些会输？为什么？

Q3: 如果这个趋势继续，我应该做什么？
    (3-5年的行动优先级)
```

## 快速诊断矩阵

### 周期性 vs 结构性判断 (30秒)

```
如果是周期性：
  - 与经济周期同向 (好时增长，差时下降)
  - 短期波动，趋势可逆转
  - 应对：等待或微调

如果是结构性：
  - 与经济周期无关或相反
  - 长期单向移动
  - 应对：战略转向，激进改革
```

**快速判断：** 回顾5年数据，趋势是持续单向还是波动？

---

### 政策vs企业错配诊断 (30秒)

```
症状1：政府补贴很多 → 企业投资很少
✓ 政策-企业错配信号

症状2：企业最关注的问题 ≠ 政府重点政策
✓ 政策-企业错配信号

症状3：企业在等政策 → 市场却在加速变化
✓ 政策-企业错配信号

后续风险：补贴可能反转，企业缺乏内生竞争力
```

---

### 赛道评分速查表

```
🟢🟢🟢 高优先级：政策✓ + 市场✓ + 防守✓
  例：芯片、造船、医药

🟡 中等：某些维度强，某些一般
  例：汽车细分、AI服务

🔴 低优先级：防守弱或结构衰退
  例：纸浆、传统零售
```

## 常见问题快答

### Q: 如何区分"中国威胁"是暂时还是永久？

**30秒答：**
```
检查1：中国能否复制日本的品质/精密？
  能 → 永久威胁，日本护城河蚀化
  否 → 暂时威胁，日本有防守空间

检查2：日本曾经逆转过这个威胁吗？
  能 → 这次也许能
  不能 → 趋势不可逆转

检查3：这是价格竞争还是性能竞争？
  价格 → 中国赢（成本优势）
  性能 → 日本守住（技术优势）
```

---

### Q: 如何判断某个政策的真实影响？

**30秒答：**
```
第一步：看企业的实际行动，不看企业的口头评价
  企业说"很受影响" vs 企业真的改变了战略
  后者才是真实影响

第二步：看不同企业的差异反应
  都一样受影响 → 可能政策影响确实存在
  有人受益有人受损 → 可能是企业能力的差异

第三步：看市场的定价反应
  股价/估值是否改变 → 市场相信这个影响
```

---

### Q: 报告数据有矛盾怎么办？

**方法：**
```
例：wage上升，但实际wage增长乏力

解释方法：
1. 名义wage vs 实际wage的区别
2. 不同群体的wage差异
3. 时间节点的不同
4. 统计方法的差异

行动：找到矛盾的原因，这反而是洞察！
```

## 分析质量自检清单

完成分析后逐一检查：

### 数据层面
- [ ] 所有数据都标注了来源？
- [ ] 样本量足够吗？(439家 vs 44家意义不同)
- [ ] 是否存在幸存者偏差？
- [ ] 定义是否一致？

### 逻辑层面
- [ ] 每个结论都有"为什么"支撑吗？
- [ ] 因果链是否清晰？(A→B还是A←X→B?)
- [ ] 是否混淆了相关性和因果性？
- [ ] 是否区分了结构性和周期性？

### 洞察层面
- [ ] 是否超越了表面现象？
- [ ] 是否识别了隐含的系统问题？
- [ ] 是否指出了报告缺失的问题？
- [ ] 是否从不同企业类型给出了差异化建议？

### 可行性层面
- [ ] 建议是否具体可操作？
- [ ] 是否有明确的优先级和时间表？
- [ ] 是否有关键监控指标？
- [ ] 不同企业是否知道"第一步怎么做"？

如果全部打✓，分析达到麦肯锡标准。

## 常见陷阱快速自查

| 陷阱 | 表现 | 自查 |
|------|------|------|
| **仅总结** | "报告说..." | "为什么会这样？" |
| **相关性当因果** | "A↑，B↑，所以A→B" | 有中间机制吗？ |
| **忽视反转风险** | "趋势会继续" | 什么会改变这个趋势？ |
| **一刀切建议** | "所有企业都应该..." | 不同企业差异化了吗？ |
| **忽视缺失问题** | 仅基于现有数据 | 报告没说什么关键问题？ |

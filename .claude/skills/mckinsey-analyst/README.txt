麦肯锡分析师 Skill (mckinsey-analyst)
======================================

这个Skill使Claude能够以麦肯锡顾问的方式分析业务报告，通过深度战略分析
揭示事实背后的根本逻辑。

目录结构：
--------
SKILL.md                          核心技能定义和使用指南
references/frameworks.md          10个战略分析框架和方法论
references/case_studies.md        5个详细的分析案例
references/quick_reference.md     快速参考卡片和检查清单
scripts/analysis_guide.py         分析指南和模板生成脚本

核心功能：
--------
1. 三层分析金字塔
   - L1 表面数据：关键数据点、趋势
   - L2 深层驱动：因果链路、系统性问题
   - L3 战略启示：赛道评分、企业决策框架

2. 多维分析框架
   - PEST + 地缘政治维度
   - 五力模型 + 中国威胁维度
   - 价值链 + 位阶重排分析
   - 四象限矩阵分析
   - 周期性 vs 结构性判断
   - 政策-企业错配诊断

3. 可交付输出格式
   - 完整战略分析报告 (12-15页)
   - CEO一页纸决策纪要 (1页)
   - 战略分析工具包 (10个诊断工具)
   - 针对性深化分析

使用场景：
--------
✓ 经济展望报告分析
✓ 行业研究报告分析
✓ 市场竞争情报分析
✓ 产业趋势研究
✓ 政策影响评估
✓ 企业战略制定

关键特点：
--------
• 不只总结报告，而要挖掘报告背后的战略含义
• 通过"为什么"的三层追问找到深层驱动
• 区分结构性变化和周期性波动
• 识别报告缺失的关键问题
• 给出不同企业类型的差异化建议
• 提供明确的优先级排序和行动方案

分析标准：
--------
✓ 每个结论都有数据或逻辑支撑
✓ 为什么追问至少3层
✓ 识别隐含的因果关系
✓ 指出报告缺失问题
✓ 可操作的战略建议
✓ 明确的优先级和时间表

估时：
-----
20-50页报告的完整战略分析：15-30分钟
依赖：PDF提取工具（内置）

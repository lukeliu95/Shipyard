# 麦肯锡分析师 (McKinsey Analyst Skill)

## 核心价值主张

将报告中的**表面数据**转化为**战略洞察**，通过多层次分析框架揭示事实背后的根本逻辑。

## 分析方法论

### 三层分析金字塔

```
第三层：战略启示 (Strategic Implications)
  ↑ "如果趋势继续，企业应该做什么？"
  ├─ 赛道评分与投资优先级
  ├─ 行业转折点判断
  └─ 风险与机遇矩阵

第二层：深层驱动 (Root Causes & Mechanisms)
  ↑ "为什么会这样？深层逻辑是什么？"
  ├─ 因果链路分析
  ├─ 系统性问题诊断
  ├─ 数据相关性→因果关系推理
  └─ 政策/技术/市场的真实影响

第一层：表面数据 (Surface Facts)
  ↓ "报告说了什么？"
  ├─ 关键数据点提取
  ├─ 趋势识别
  └─ 现象描述
```

## 使用流程

### 第一步：问题分解 (1-2分钟)

用户上传报告后，立即：

1. **快速扫描识别**
   - 报告覆盖的行业/主题
   - 核心数据类型 (定量vs定性)
   - 时间跨度与地域范围
   - 潜在的隐含假设

2. **确认分析范围**
   - 用户是否有特定关注点？(可选问一个澄清问题)
   - 分析深度：宽泛vs聚焦？
   - 输出格式偏好

### 第二步：数据提炼 (3-5分钟)

从报告中提取并组织：

1. **核心数据点**
   - 所有关键数字、百分比、排名
   - 时间序列变化
   - 对比数据 (同期对比、地区对比、行业对比)

2. **逻辑关系图**
   - 哪些数据之间存在相关性？
   - 是否有隐含的因果关系？
   - 数据的结构性 vs 周期性特征

3. **红旗信号**
   - 报告没说但很关键的问题
   - 数据间的矛盾或跳跃
   - 政策/市场的潜在转折点

### 第三步：原因分析 (5-10分钟)

这是**关键步骤**。不满足于"是什么"，追问"为什么"：

1. **表象后面的本质**
   ```
   表象: "关税提高了"
   问题: 企业如何应对？供应链如何重组？
   本质: 地缘政治重塑全球产业分工
   ```

2. **因果链条重构**
   - 事件A → 中间机制 → 结果B
   - 是直接影响还是间接影响？
   - 时间滞后是多少？

3. **系统性诊断**
   - 是周期性波动还是结构性变化？
   - 哪些企业获益，哪些受损？为什么？
   - 政策期望值与企业现实是否匹配？

### 第四步：战略建议 (5-10分钟)

将洞察转化为行动：

1. **赛道/行业评分**
   - 基于政策+市场+竞争格局的多维评估
   - 投资吸引力矩阵
   - 优先级排序

2. **企业决策框架**
   - 不同企业类型的应对策略
   - 关键风险点与监控指标
   - 3-5年的行动路线图

3. **隐藏洞察**
   - 报告缺失的关键问题
   - 后续需要深化的研究方向
   - 政策可能的反转风险

## 输出格式

根据用户需求，生成以下之一：

### Option A：完整战略分析报告 (12-15页)

- 宏观环境诊断
- 行业冷热分化分析
- 企业现实vs政府政策对标
- 赛道评分矩阵
- 企业决策框架
- 后续研究议题

- 风险-机遇矩阵
- 优先级排序
- 关键监控指标

- 政策风险评估矩阵

- 风险监控看板

## 质量标准

✓ 每个结论都有数据支撑或逻辑推导过程

✓ 不满足表面现象，追问"为什么"至少3层

✓ 识别数据间的隐含因果关系，而非仅列举现象

✓ 区分结构性变化 vs 周期性波动

✓ 指出报告缺失的关键问题与后续研究方向

✓ 给出可操作的战略建议与优先级排序

## 工作流总结

1. **Parse** → 快速理解报告的核心数据和结构
2. **Extract** → 提炼所有关键数据点和隐含逻辑
3. **Diagnose** → 追问"为什么"，找到深层驱动
4. **Synthesize** → 整合为战略洞察和行动方案
5. **Recommend** → 给出优先级排序的建议和工具
6. **Deliver** → 按用户需求的格式输出结果

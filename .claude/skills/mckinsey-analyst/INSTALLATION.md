# 麦肯锡分析师 Skill 安装和使用指南

## 安装

1. **下载Skill文件** (mckinsey-analyst.skill)

2. **在Claude中启用**
   - 进入设置 → Skills
   - 上传或导入 mckinsey-analyst.skill 文件
   - 启用该Skill

## 快速开始

### 基础使用
```
用户："帮我分析这份经济报告" + 上传PDF文件

Claude (自动触发mckinsey-analyst)：
1. 快速扫描报告结构
2. 提取关键数据点
3. 进行深层因果分析
4. 生成战略洞察
5. 输出建议方案
```

### 指定输出格式
```
用户："分析这份报告，给我一份CEO可用的一页纸决策方案"

Claude：
生成 "CEO决策纪要" 格式的输出
```

### 聚焦特定行业
```
用户："这份日本经济报告中，芯片产业和汽车产业的前景对比如何？"

Claude：
针对这两个行业做深度对标分析
```

## 主要功能

### 1. 三层分析
- **L1 表面数据**：提取所有关键数据点和趋势
- **L2 深层驱动**：通过"为什么"的三层追问找根本原因
- **L3 战略启示**：将洞察转化为可操作的建议

### 2. 多维分析框架
包含10个经过验证的战略分析框架：
- PEST + 地缘政治
- 五力模型 + 中国威胁
- 价值链 + 位阶重排
- 四象限矩阵
- 周期 vs 结构性判断
- 政策-企业错配诊断
- 等等

### 3. 灵活的输出格式
- **完整报告**：12-15页的深度战略分析
- **CEO纪要**：1页的高管决策方案
- **工具包**：10个诊断工具和矩阵
- **深化分析**：针对特定行业/企业的方案

## 核心价值

这个Skill不只是总结报告，而是：

✓ **挖掘本质**：从表面数据 → 深层逻辑 → 战略含义

✓ **识别机制**：不只说"是什么"，而要说清"为什么"

✓ **差异化建议**：不同企业/行业的建议不同

✓ **优先级排序**：明确告诉你"最关键的3件事是什么"

✓ **风险预警**：指出报告缺失的问题和反转风险

## 分析质量标准

完成分析后会检查：

✓ 每个结论都有数据或逻辑支撑吗？
✓ 为什么追问了至少3层吗？
✓ 识别了隐含的因果关系吗？
✓ 指出了报告缺失问题吗？
✓ 给出了优先级排序吗？
✓ 可以直接指导决策吗？

## 常见使用场景

### 场景1：上市公司投资决策
```
上传：行业研究报告
需求："判断这个行业的投资前景，给出优先级排序"
输出：赛道评分矩阵 + 5年投资建议
```

### 场景2：企业战略制定
```
上传：经济展望报告 + 竞争情报
需求："我们是[某企业]，应该怎么应对这些趋势？"
输出：针对该企业的3-5年战略路线图
```

### 场景3：政策影响评估
```
上传：政府政策文件 + 行业数据
需求："新政策对[行业]的影响是什么？"
输出：政策影响的多层次分析
```

### 场景4：竞争对手分析
```
上传：竞争对手商业报告 + 市场数据
需求："竞争对手的战略意图是什么？"
输出：对手战略解读 + 应对建议
```

## 常见问题

### Q: 分析需要多长时间？
A: 取决于报告长度和复杂度
- 20-30页简单报告：10-15分钟
- 40-50页复杂报告：20-30分钟

### Q: 我想要的格式不在这四个中？
A: 可以指定自定义格式，Skill可以灵活调整

### Q: 分析会基于什么数据？
A: 完全基于你上传的报告内容 + Skill内置的分析框架

### Q: 能分析非中文的报告吗？
A: 可以，Skill支持英文、日文等多语言报告

## 反馈和改进

如果分析结果有不满意的地方，可以：
1. 指出具体的问题
2. 提供澄清信息
3. 要求重新分析或调整角度

Skill会根据反馈持续优化。
